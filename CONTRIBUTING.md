# Como contribuir com o Kit Skill Daora

Obrigado por querer ajudar! Este kit existe para pessoas que estão começando
agora com tecnologia. Qualquer melhoria nelas é bem-vinda.

## Antes de propor uma habilidade nova

1. **Use de verdade** a habilidade que você quer enviar, em um projeto real,
   conversando com alguém que esteja começando (ou simulando esse papel).
2. Confira se ela não repete o que outra habilidade já faz.

## Regras de ouro para novas habilidades

- Pasta própria: `.opencode/skills/nome-com-hifen/SKILL.md`.
- Cabeçalho YAML com `name` e `description` (a descrição diz QUANDO usar).
- Português do Brasil simples: sem jargão não explicado, frases curtas.
- Uma responsabilidade por habilidade.
- Seção "Erros a evitar" no final.
- A verificação automática roda sozinha no seu pull request e avisa se
  algo estiver fora do formato.

## Como enviar

- **Sem código:** abra uma issue com o formulário "Sugerir uma habilidade nova".
- **Com código:** envie um pull request direto para `main`.

Ao contribuir, você concorda que sua contribuição entra sob a licença MIT
do projeto.
